Comfy-Gen-MCP

Image generation and editing for Claude, on a ComfyUI you own.

No GPU? Run it in the cloud

A Cloudflare Worker gives claude.ai (web, desktop and mobile) an image tool. ComfyUI runs on Modal, which only runs, and only bills, while it generates.

You need:

  • A Cloudflare account (the free plan is enough) with GitHub connected.
  • A Modal account with a card on file. New accounts get $30 of free compute a month.
  • A claude.ai plan that can add custom connectors.

Steps:

  1. Click the button and wait for the first deploy (about 3 minutes). There is nothing to fill in.
  2. Open your Worker's URL and log in with a Cloudflare token (the page links to a pre-filled one), then paste a Modal token.
  3. Copy the connector URL it shows into claude.ai under Settings → Connectors → Add custom connector.
Deploy to Cloudflare

Updates install themselves: the Worker checks for a new release daily and redeploys.

Have a GPU? Use it from claude.ai and your phone

Deploy the Worker as above (the Modal token is optional: add it and Modal takes over while your PC is off). A small agent on your PC connects out to the Worker, so there is no port to open and no tunnel.

  1. On your Worker's page, under Your PC, copy the pairing link.
  2. Download and run the agent for your system: Windows, macOS (Apple silicon), macOS (Intel), Linux. It is not signed yet: on Windows choose More info → Run anyway; on macOS right-click it and choose Open.
  3. Its page opens in your browser: paste the pairing link, then install ComfyUI (it finds the models of ComfyUI installs you already have).

The agent starts with your PC, runs ComfyUI only while it is used, and updates itself.

Claude Desktop only

The Claude Desktop extension installs and runs ComfyUI on your PC, with no accounts. Open the file to install it in Claude Desktop, then open its settings page from the tray icon to pick your GPU and install ComfyUI.
