Comfy-Gen-MCP

Image generation and editing for Claude, on a ComfyUI you own.

No GPU? Run it in the cloud

A Cloudflare Worker gives claude.ai (web, desktop and mobile) an image tool. ComfyUI runs on Modal, which only runs, and only bills, while it generates.

You need:

  • A Cloudflare account (the free plan is enough) with GitHub connected.
  • A Modal account with a card on file. New accounts get $30 of free compute a month.
  • A claude.ai plan that can add custom connectors.

Steps:

  1. Click the button. Pick a setup password when it asks, then wait for the first deploy (about 3 minutes).
  2. Open your Worker's URL, log in, and follow the setup page: a Cloudflare token, then a Modal token.
  3. Copy the connector URL it shows into claude.ai under Settings → Connectors → Add custom connector.
Deploy to Cloudflare

Updates install themselves: the Worker checks for a new release daily and redeploys.

Have a GPU? Run it on your PC

The Claude Desktop extension installs and runs ComfyUI locally. For now, get it from the current version's repository; this project replaces it soon.
