      Install the extension

      You need an NVIDIA GPU (AMD on Linux) or an Apple silicon Mac.

      1. Download Comfy-Gen-MCP.mcpb and open it: Claude Desktop installs it.
      2. The Comfy-Gen icon appears in the tray (the menu bar on a Mac). Open its settings page from there: it takes you through choosing your GPU, installing ComfyUI and picking models.
      3. Ask Claude Desktop for an image.

      Later want claude.ai too? Choose the first answer instead. Use the extension or the Worker's PC agent on a PC, never both: each runs its own ComfyUI, and two don't fit on one GPU.

    6. 3

      The accounts you need

      Make each one, then tick it.

      Tip: Cloudflare and Modal both letCloudflare lets you sign up with your GitHub account (the GitHub button on the sign-up page). Make the GitHub account first and use it there: fewer logins.

      What does it cost?
      • Cloudflare: the Worker is free (up to 100,000 requests a day). Its storage, R2, is free up to 10 GB stored, a million writes and ten million reads a month; one person's use stays far inside those. Past 10 GB it is $0.015 per GB a month, and images expire after a year. Cloudflare has no spending cap, but it sets up a $10 budget alert by itself (Manage account → Billing → Billable usage); lower it if you like. It emails; it doesn't stop anything.
      • Modal (the cloud): billed per second, only while it generates, and new accounts get $30 of free compute a month. Its Spend limit (Settings → Usage & billing → Usage limit) is a hard cap: once charges pass it, with the free credits used first, all work stops. At $0 you never pay past the credits.
      • Your PC: the electricity.
    7. 4

      Deploy your Worker

      The first time, Cloudflare also needs access to your GitHub. It takes two rounds of the same button: click Deploy to Cloudflare (it opens in a new tab), then follow the steps.

      Deploy to Cloudflare

      The form shows SETUP_MODE set to cloud: your answer. Leave it: your Worker's page starts from it.

      1. Under Git account, click New GitHub connection. GitHub asks to Install & Authorize Cloudflare Workers and Pages: keep All repositories (the deploy creates a new repository) and click it.
      2. Cloudflare then opens its own Select a repository page. Ignore it: close that tab.
      3. Back here, click Deploy to Cloudflare again. Your GitHub account is in the Git account list now: pick it, keep the project name comfy-gen and everything else as it is, and click Deploy.
      GitHub shows a settings page instead of Install & Authorize?

      Cloudflare's app is already installed on that GitHub account, from an earlier try, and that way it never reaches Cloudflare. Remove it, then start again from the first step: on GitHub, open Settings → Applications → Installed GitHub Apps, then Cloudflare Workers and Pages → Configure, and Uninstall at the bottom.

      That also disconnects any other Cloudflare project that builds from this GitHub account, until it is connected again.

    8. 5

      Open your Worker

      1. In the Cloudflare tab, the build runs for about a minute.
      2. When it shows Success, reload the page and click Visit (top right). That's your Worker, at https://comfy-gen.<your-subdomain>.workers.dev: bookmark it.

      Lost the tab? In the Cloudflare dashboard, open Workers & Pages → comfy-gen and click Visit.

    9. 6

      Finish on your Worker's page

      Your Worker's page takes it from here, one step at a time:

      1. Log in with a Cloudflare API token: the page links to a pre-filled one.
      2. Turn on storage: Add R2 subscription to my account in Cloudflare (it's $0), then Check again.
      3. Deploy ComfyUI to Modal, and pick the models.
      4. Add your PC, and run the agent on it.
      5. Add your PC and run the agent on it, then deploy ComfyUI to Modal as the fallback.
      6. Connect Claude: in claude.ai, Customize → Connectors, add your Worker's connector URL as a custom connector.

      Your answer, , is already set there; you can change it on that page.

      Updates install themselves: the Worker checks for a new release daily and redeploys, and the agent on a PC updates itself too.
