    3. 2

      Install the extension

      You need an NVIDIA graphics card (AMD on Linux) or a Mac with Apple silicon.

      1. Download the extension
        Open the file: Claude Desktop installs it.
      2. The Comfy-Gen icon appears in the tray (the menu bar on a Mac). Open its settings page from there: it takes you through installing ComfyUI and picking models.
      3. Ask Claude Desktop for an image.

      Want claude.ai and your phone too later? Choose the first answer instead, and don't keep both on one PC: they don't fit on one graphics card together.

    6. 3

      The accounts you need

      Make each one you don't have yet, then tick it. Make the GitHub one first: Cloudflare and Modal let you sign up with it (Continue with GitHub), so there are fewer passwords.

      What does it cost?
      • Cloudflare: free for one person's use. Storage past 10 GB costs $0.015 per GB a month; images are deleted after a year. Cloudflare asks for a card once, to turn storage on.
      • Modal (the cloud): pay per second, only while an image is made. New accounts get $30 free each month, and Modal needs a card on file even for that.
      • Your PC: the electricity.
    7. 4

      Deploy your Worker

      Your Worker is your own copy of Comfy-Gen, in your Cloudflare account. The first time, Cloudflare also needs to connect to your GitHub, so you click this button twice: the steps below show when.

      Deploy to Cloudflare
      1. Under Git account, click New GitHub connection. GitHub asks to Install & Authorize Cloudflare Workers and Pages: keep All repositories (the deploy creates a new repository) and click it.
      2. Cloudflare then opens its own Select a repository page. Ignore it: close that tab.
      3. Back here, click Deploy to Cloudflare again. Your GitHub account is in the Git account list now: pick it and click Deploy.
      GitHub shows a settings page instead of Install & Authorize?

      Cloudflare's app is already installed on that GitHub account, from an earlier try, and that way it never reaches Cloudflare. Remove it, then start again from the first step: on GitHub, open Settings → Applications → Installed GitHub Apps, then Cloudflare Workers and Pages → Configure, and Uninstall at the bottom.

      That also disconnects any other Cloudflare project that builds from this GitHub account, until it is connected again.

    8. 5

      Open your Worker

      1. In the Cloudflare tab, the build runs for about a minute.
      2. When it shows Success, reload the page and click Visit (top right). That's your Worker, at https://comfy-gen.<your-subdomain>.workers.dev: bookmark it.

      Closed the Cloudflare tab? Open your Workers here, click comfy-gen, then Visit:

      Open Workers & Pages in Cloudflare
    9. 6

      Finish on your Worker's page

      Bookmark your Worker's page: it takes it from here, one step at a time, each with a button to the page you need. You can close this setup page and the Cloudflare tab now.

      1. Log in with Cloudflare.
      2. Turn on storage in Cloudflare.
      3. Connect your Modal account.
      4. Install the Comfy-Gen agent on your PC.
      5. Install the Comfy-Gen agent on your PC, then connect your Modal account.
      6. Add it to claude.ai.

      Updates install themselves.
