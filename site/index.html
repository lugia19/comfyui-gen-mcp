    Deploy to Cloudflare

    The form shows SETUP_MODE set to cloud: your answer above. Leave it: your Worker's page starts from it.

    1. Under Git account, click New GitHub connection. GitHub asks to Install & Authorize Cloudflare Workers and Pages: keep All repositories (the deploy creates a new repository) and click it.
    2. Cloudflare then opens its own Select a repository page. Ignore it: close that tab.
    3. Back here, click Deploy to Cloudflare again. Your GitHub account is in the Git account list now: pick it, keep the project name comfy-gen and everything else as it is, and click Deploy.
    GitHub shows a settings page instead of Install & Authorize?

    Cloudflare's app is already installed on that GitHub account, from an earlier try, and that way it never reaches Cloudflare. Remove it, then start again from step 1: on GitHub, open Settings → Applications → Installed GitHub Apps, then Cloudflare Workers and Pages → Configure, and Uninstall at the bottom.

    That also disconnects any other Cloudflare project that builds from this GitHub account, until it is connected again.

    1. In the Cloudflare tab, the build runs for about a minute.

What it costs

  • Cloudflare: the Worker is free (up to 100,000 requests a day). Its storage, R2, is free up to 10 GB stored, a million writes and ten million reads a month; one person's use stays far inside those. Past 10 GB it is $0.015 per GB a month, and images expire after a year. Cloudflare has no spending cap, but it sets up a $10 budget alert by itself (Manage account → Billing → Billable usage); lower it if you like. It emails; it doesn't stop anything.
  • Modal (the cloud): billed per second, only while it generates, and new accounts get $30 of free compute a month. Its Spend limit (Settings → Usage & billing → Usage limit) is a hard cap: once charges pass it, with the free credits used first, all work stops. At $0 you never pay past the credits.
  • Your PC: the electricity.
